## Overview

Databricks Unity Gateway is a governance layer built on Unity Catalog for traffic between models, agents, MCP servers, and tools. It provides routing, service policies, and usage monitoring.

## Features

- Governance layer built on Unity Catalog
- Traffic between models, agents, MCP servers, and tools
- Routing
- Service policies
- Usage monitoring
