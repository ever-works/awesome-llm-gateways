## Overview

Kunavo is a hosted prepaid gateway with OpenAI-compatible chat completions, Anthropic-compatible Messages, streaming, and per-key usage reporting.

## Features

- OpenAI-compatible chat completions
- Anthropic-compatible Messages
- Streaming responses
- Per-key usage reporting
- Prepaid billing model

## Pricing Model
