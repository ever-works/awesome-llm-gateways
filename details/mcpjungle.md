## Overview

MCPJungle is a self-hosted MCP gateway that registers servers once and serves them to Claude, Cursor, Codex, or custom agents through a single endpoint with access control and observability.

## Features

- Registers MCP servers once
- Serves to Claude, Cursor, Codex, or custom agents
- Single endpoint
- Access control
- Observability
