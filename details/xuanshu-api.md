## Overview

玄枢API (XuanShu API) is a mixed-type AI API relay station serving the China/Asia region. It serves Anthropic Messages and Gemini v1beta at the root host, and OpenAI Responses and Chat Completions under /v1.

## Features

- Mixed-type relay station
- Anthropic Messages and Gemini v1beta at root host
- OpenAI Responses and Chat Completions under /v1
- Model visibility and pricing are per-key and per-group, set in the console
- Invoice payment support

## Pricing

Paid service with Invoice payment. Model visibility and pricing are per-key and per-group, set in the console. Prices change frequently; verify on-site.
