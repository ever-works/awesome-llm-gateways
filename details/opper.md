## Overview

Opper is a hosted gateway and router for 700+ models through one EU-hosted, OpenAI-compatible API, with automatic failover, spend limits, model allowlists, zero data retention, and ISO 27001 certification.

## Features

- 700+ models
- EU-hosted
- OpenAI-compatible API
- Automatic failover
- Spend limits
- Model allowlists
- Zero data retention
- ISO 27001 certification
