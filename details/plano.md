## Overview

Plano is an open-source self-hosted LLM gateway for routing and managing LLM traffic across multiple model providers. It offers observability features and cost controls for teams running their own AI infrastructure.

## Features

- Self-hosted LLM gateway
- Multi-provider model routing
- Traffic management and load balancing
- Observability and logging
- Cost controls
- On-premises deployment

## Pricing

Free and open-source. Self-hosted; infrastructure costs borne by the operator.

## Deployment

Self-hosted
