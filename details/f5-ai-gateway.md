## Overview

F5 AI Gateway is a control plane that combines a model gateway, an MCP gateway, and guardrails under one policy model for model, agent, and tool traffic.

## Features

- Model gateway for model traffic
- MCP gateway for tool traffic
- Guardrails for security and policy enforcement
- Unified policy model across model, agent, and tool traffic
