## Overview

Pomerium MCP Gateway extends Pomerium's zero-trust access platform with Model Context Protocol gateway capabilities, enabling secure AI agent access to enterprise resources. It provides identity-aware proxying and access governance for AI workloads.

## Features

- Zero-trust access platform
- MCP protocol gateway
- Identity-aware proxying
- Access governance and policies
- Secure AI agent resource access
- Self-hosted and cloud options

## Pricing

Open-source core available free; paid enterprise and cloud tiers with additional features.

## Deployment

Self-hosted and cloud-hosted
