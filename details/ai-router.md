## Overview

AI Router is a mixed-type OpenAI-compatible ChatGPT API relay serving multiple regions with localized pages.

## Features

- Mixed-type relay station
- OpenAI-compatible ChatGPT API relay at api.ai-router.dev/v1
- Dashboard API keys
- Usage tracking
- Daily/weekly packages
- Localized English/Chinese/Russian/Persian pages
- Card, Crypto, Alipay, and WeChat payment accepted

## Pricing

Paid service with daily/weekly packages. Prices change frequently; verify on-site.

## Deployment

Cloud-hosted relay service.
