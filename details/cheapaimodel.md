## Overview

cheapaimodel is a hosted OpenAI-compatible API with one key for every model in its catalog. It is billed per token from a prepaid US-dollar balance, with per-key expiry dates, spending budgets, model allowlists, and IP allowlists.

## Features

- OpenAI-compatible API
- One key for every model in catalog
- Billed per token from prepaid US-dollar balance
- Per-key expiry dates
- Spending budgets
- Model allowlists
- IP allowlists

## Pricing Model

Per-token billing from prepaid US-dollar balance.
