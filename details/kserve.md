## Overview

KServe is a Kubernetes-native serverless inference platform for deploying and managing ML and LLM models at scale. It provides model serving, autoscaling, and gateway-style API access for inference workloads, built on Knative and Kubernetes.

## Features

- Kubernetes-native model serving
- Serverless inference with autoscaling
- Multi-framework support (TensorFlow, PyTorch, XGBoost, etc.)
- Canary rollouts and traffic splitting
- Gateway-style API for inference
- Open-source CNCF project

## Pricing

Free and open-source under the Apache 2.0 license. Self-hosted on Kubernetes; infrastructure costs borne by the operator.

## Deployment

Self-hosted (Kubernetes)
