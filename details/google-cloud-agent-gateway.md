## Overview

Google Cloud Agent Gateway is an enforcement point in the Gemini Enterprise Agent Platform that applies access policies, mTLS, agent identities, and MCP security to agent-to-agent and agent-to-tool traffic.

## Features

- Access policies
- mTLS
- Agent identities
- MCP security
- Agent-to-agent and agent-to-tool traffic governance

## Pricing Model
