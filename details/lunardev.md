## Overview

Lunar.dev is an MCP and agent gateway for managing, securing, and observing API traffic from AI agents and LLM-based applications. It provides rate limiting, quota management, and traffic governance for agent-to-service communication.

## Features

- MCP protocol gateway
- Agent traffic management
- Rate limiting and quota management
- Traffic governance and security
- API observability
- Cloud-hosted managed service

## Pricing

Freemium model with free tier and paid enterprise plans.

## Deployment

Cloud-hosted
