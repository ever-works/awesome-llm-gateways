## Overview

SandBase is a hosted API for 2,000+ AI models and data APIs behind one OpenAI-compatible key, with free agents and sandboxes and usage billed per model or API call.

## Features

- 2,000+ AI models and data APIs
- One OpenAI-compatible key
- Free agents and sandboxes
- Usage billed per model or API call

## Pricing Model

Per model or API call billing.
