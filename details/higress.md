## Overview

Higress is an open-source cloud-native API gateway and ingress controller from Alibaba Cloud, with built-in AI gateway capabilities for LLM traffic routing, observability, and plugin extensibility. Designed for Kubernetes and cloud-native environments.

## Features

- Cloud-native API gateway
- AI/LLM traffic routing
- Observability and metrics
- Plugin extensibility
- Kubernetes ingress support
- High-performance proxy based on Envoy

## Pricing

Free and open-source under the Apache 2.0 license. Self-hosted; infrastructure costs borne by the operator.

## Deployment

Self-hosted, Kubernetes-native
