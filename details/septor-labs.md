## Overview

Septor Labs is a hosted gateway that serves OpenAI-style and Anthropic-style clients from one key. It routes by priority, weight, least-connections, or latency, fails over before the first token, and adds semantic caching, per-key budgets, and prepaid credits.

## Features

- OpenAI-style and Anthropic-style clients
- One key
- Routing by priority, weight, least-connections, or latency
- Failover before the first token
- Semantic caching
- Per-key budgets
- Prepaid credits

## Pricing Model
