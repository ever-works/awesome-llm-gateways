## Overview

UnoRouter is an aggregator-type gateway built on the new-api gateway. It provides one key across multiple upstreams with latency-based routing and failover, automatically detecting OpenAI/Anthropic/Gemini formats.

## Features

- Aggregator-type gateway built on new-api
- One key across multiple upstreams
- Latency-based routing and failover
- OpenAI/Anthropic/Gemini formats auto-detected
- Pay-as-you-go credits plus a free model tier
- Targets roleplay clients (SillyTavern, Janitor.AI, RisuAI, Chub)
- Public pricing JSON at /api/pricing
- Card payment accepted

## Pricing

Paid service with pay-as-you-go credits plus a free model tier. Card payment accepted. Prices change frequently; verify on-site.

## Deployment

Cloud-hosted aggregator service.
