## Overview

Agentik is a tool gateway that connects Claude, ChatGPT, Codex, and Cursor to third-party tools through one MCP connection. It provides API keys that carry spending limits per hour, per day, in total, and per tool.

## Features

- Connects Claude, ChatGPT, Codex, and Cursor to third-party tools
- One MCP connection
- API keys with spending limits per hour, per day, in total, and per tool
