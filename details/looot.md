## Overview

looot is a hosted gateway that gives AI agents one MCP endpoint and one prepaid balance for paid business-data APIs. It includes provider fallback, a price shown before each run, and a per-run cost cap.

## Features

- One MCP endpoint for AI agents
- Prepaid balance for paid business-data APIs
- Provider fallback
- Price shown before each run
- Per-run cost cap

## Pricing Model

Prepaid.
