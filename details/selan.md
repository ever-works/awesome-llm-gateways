## Overview

Selan is a hosted gateway for Claude Code, Codex and Claude Desktop. It routes requests to a company's own subscriptions and API keys, with spend caps and request logs per person.

## Features

- Routes requests to company's own subscriptions and API keys
- Spend caps per person
- Request logs per person
- Supports Claude Code, Codex, and Claude Desktop

## Pricing Model

Commercial/Enterprise pricing.
