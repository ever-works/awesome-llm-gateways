## Overview

Kuadrant MCP Gateway is an Envoy-based gateway that aggregates and routes multiple MCP servers behind one endpoint. It uses Istio and Gateway API policy attachment for authentication, authorization, and rate limiting.

## Features

- Aggregates and routes multiple MCP servers behind one endpoint
- Envoy-based
- Authentication, authorization, and rate limiting via Istio and Gateway API policy attachment
