## Overview

agentgateway is a Linux Foundation proxy built on MCP and A2A that acts as an LLM gateway, an MCP gateway with tool federation and OAuth, and an A2A gateway for agent-to-agent communication.

## Features

- LLM gateway
- MCP gateway with tool federation and OAuth
- A2A gateway for agent-to-agent communication
- Built on MCP and A2A
- Linux Foundation project
