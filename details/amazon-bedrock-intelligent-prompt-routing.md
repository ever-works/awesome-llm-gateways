## Overview

Amazon Bedrock Intelligent Prompt Routing is a serverless Bedrock endpoint that routes each request between models in the same family based on predicted response quality.

## Features

- Serverless Bedrock endpoint
- Routes each request between models in the same family
- Based on predicted response quality
