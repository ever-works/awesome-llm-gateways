## Overview

Relaydance is a mixed-type AI API relay operator focused on xAI Grok and ByteDance Doubao models. It is built on 新-API (Calcium-Ion fork).

## Features

- Mixed-type relay station
- Focused on xAI Grok + ByteDance Doubao models
- Built on 新-API (Calcium-Ion fork)
- Public /api/pricing returning ratio-based pricing (model_ratio × $2 / 1M tokens)
- Alipay, WeChat, and Card payment support

## Pricing

Paid service with ratio-based pricing model (model_ratio × $2 / 1M tokens). Prices change frequently; verify on-site.

## Deployment

Cloud-hosted relay service.
