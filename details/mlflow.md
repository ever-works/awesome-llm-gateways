## Overview

MLflow is an open-source platform for the complete machine learning lifecycle, including LLM observability, model serving, and gateway-style API management for AI models. It provides tracking, deployment, and model registry capabilities.

## Features

- Experiment tracking and logging
- Model serving and deployment
- Model registry and versioning
- LLM observability and tracing
- OpenAI-compatible serving API
- Multi-framework support

## Pricing

Free and open-source under the Apache 2.0 license. Self-hosted; MLflow managed (Databricks) available as paid service.
