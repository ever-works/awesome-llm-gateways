## Overview

Obot is a self-hosted AI governance platform with MCP and LLM gateways, MCP and skills registries, and isolated hosting for MCP servers.

## Features

- MCP and LLM gateways
- MCP and skills registries
- Isolated hosting for MCP servers
- AI governance platform
- Self-hosted
