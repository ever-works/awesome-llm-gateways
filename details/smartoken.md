## Overview

SmarToken is a hosted OpenAI-compatible text chat API for selected Chinese models, with a prepaid USD balance, API key budgets, streaming, and request logs.

## Features

- OpenAI-compatible text chat API
- Selected Chinese models
- Prepaid USD balance
- API key budgets
- Streaming
- Request logs

## Pricing Model

Prepaid USD balance.
