## Overview

MuleSoft Agent Fabric is a Salesforce MuleSoft product that applies one set of policies to agents, MCP servers, and models without rebuilding or instrumenting them.

## Features

- One set of policies for agents, MCP servers, and models
- No rebuilding or instrumenting required
- Salesforce MuleSoft product
