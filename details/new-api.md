## Overview

new-api is an open-source LLM gateway designed for the China ecosystem, exposing multiple model providers behind a single OpenAI-compatible API. It supports load balancing, token usage tracking, and cost management for self-hosted deployments.

## Features

- OpenAI-compatible API interface
- Multi-provider model routing
- Load balancing across endpoints
- Token usage tracking and analytics
- Cost controls and budgeting
- Self-hosted deployment

## Pricing

Free and open-source under the MIT license. Self-hosted; users pay only for infrastructure and model API costs.

## Deployment

Self-hosted
