## Overview

TokenDos is an aggregator-type AI API relay station operating as a token-sharing marketplace that routes across multiple supplier nodes. It offers OpenAI /v1 and Anthropic endpoints with a public pricing and availability page.

## Features

- Aggregator-type relay station
- Token-sharing marketplace routing across multiple supplier nodes
- OpenAI /v1 and Anthropic endpoints
- Public pricing and availability page
