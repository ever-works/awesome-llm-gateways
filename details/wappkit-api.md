## Overview

Wappkit API is a mixed-type AI API relay station serving the China/Asia region. It is a new-api OpenAI-compatible gateway with public pricing endpoint.

## Features

- Mixed-type relay station
- new-api OpenAI-compatible gateway
- Public /api/pricing endpoint
- Listed groups are Codex/Claude-Code pools (no flat default group)
