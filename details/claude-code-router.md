## Overview

Claude Code Router is a model router for Claude Code and AI coding assistants that routes requests between different Claude models based on task complexity. It optimizes cost by using smaller models for simple tasks and larger models for complex ones.

## Features

- Model routing for Claude models
- Task complexity-based routing
- Cost optimization for coding assistants
- OpenAI-compatible interface
- Open-source

## Pricing

Free and open-source. Self-hosted; users pay only for Anthropic API costs.

## Deployment

Self-hosted
