## Overview

Nivana is a hosted model router that profiles each request by task and difficulty, scores every model in its pool on measured quality, live price, and speed, and sends the request to the highest scorer.

## Features

- Profiles each request by task and difficulty
- Scores models on measured quality, live price, and speed
- Sends request to highest scorer
