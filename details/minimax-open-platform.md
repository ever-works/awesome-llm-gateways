## Overview

MiniMax Open Platform is the first-party API platform for MiniMax models. It offers official API access with OpenAI-compatible and Anthropic-compatible base URLs.

## Features

- Official API platform (type: official)
- OpenAI-compatible base: https://api.minimax.io/v1
- Anthropic-compatible base: https://api.minimax.io/anthropic
- Stream and tools documented
- Pricing overview at https://platform.minimax.io/docs/pricing/overview
- API reference: https://platform.minimax.io/docs/api-reference/text-chat-openai
- Function call guide: https://platform.minimax.io/docs/guides/text-m3-function-call

## Pricing

Paid service. Pricing overview available at https://platform.minimax.io/docs/pricing/overview.

## Deployment

Cloud-hosted official API platform.
