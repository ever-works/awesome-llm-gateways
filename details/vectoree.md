## Overview

Vectoree is a hosted OpenAI-compatible gateway for coding agents with one project key across multiple providers. It includes auth, PostgreSQL and object storage, a CLI and agent skill, and is billed pay-as-you-go with a $5 welcome credit.

## Features

- OpenAI-compatible gateway
- One project key across multiple providers
- Authentication
- PostgreSQL and object storage
- CLI and agent skill
- Pay-as-you-go billing
- $5 welcome credit

## Pricing Model

Pay-as-you-go with a $5 welcome credit.
