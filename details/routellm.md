## Overview

RouteLLM is an open-source model router from LMSYS that intelligently routes LLM requests between more capable (and expensive) models and cheaper models based on query complexity. It uses router models to predict which queries need expensive models, reducing costs while maintaining response quality.

## Features

- Intelligent model routing
- Cost-based model selection
- Query complexity analysis
- Router model for prediction
- Cost optimization
- Open-source research project

## Pricing

Free and open-source under the MIT license. Self-hosted; users pay only for model API costs.

## Deployment
