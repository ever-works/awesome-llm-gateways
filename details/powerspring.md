## Overview

Powerspring is an OpenAI-compatible API for open-weight models, including gpt-oss, DeepSeek, GLM, Qwen and Gemma. Every request runs on EU infrastructure owned by EU companies, Powerspring does not store prompts or outputs, and billing is from prepaid credits in euros.

## Features

- OpenAI-compatible API
- Open-weight models (gpt-oss, DeepSeek, GLM, Qwen, Gemma)
- EU infrastructure owned by EU companies
- No prompt or output storage
- Prepaid credits in euros

## Pricing Model

Prepaid credits in euros.
