## Overview

Gateway API Inference Extension is a Kubernetes SIG project that uses Envoy external processing to turn a compatible Gateway API implementation into an inference gateway for self-hosted models.

## Features

- Uses Envoy external processing
- Turns Gateway API implementation into an inference gateway
- For self-hosted models
- Kubernetes SIG project
