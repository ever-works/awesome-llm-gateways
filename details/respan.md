## Overview

Respan is an observability-first LLM gateway providing tracing, logging, and analytics for AI model requests. It helps teams monitor LLM usage, costs, and performance across multiple providers.

## Features

- LLM request tracing and logging
- Usage analytics and monitoring
- Cost tracking and attribution
- Performance observability
- Multi-provider support
- Observability-first architecture

## Pricing

Freemium model with free tier and paid plans based on usage volume.

## Deployment

Cloud-hosted
