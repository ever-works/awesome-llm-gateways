## Overview

AIBrix is a Kubernetes-native open-source platform for large-scale LLM inference and serving. It provides disaggregated inference architecture and gateway-style API access for high-throughput LLM deployments.

## Features

- Kubernetes-native LLM inference
- Disaggregated inference architecture
- High-throughput model serving
- Gateway-style API access
- Scalable for large models
- Open-source

## Pricing

Free and open-source. Self-hosted; infrastructure costs borne by the operator.

## Deployment

Self-hosted (Kubernetes)
