## Overview

Novita is a managed LLM API gateway that provides unified access to multiple AI models through a single API. It supports model routing, inference scaling, and cost management for AI application developers.

## Features

- Unified API for multiple AI models
- Model routing and load balancing
- Inference scaling
- Cost management and tracking
- Developer-focused API and SDKs
- Cloud-hosted managed service

## Pricing

Freemium model with a free tier and paid usage-based plans.

## Deployment

Cloud-hosted
