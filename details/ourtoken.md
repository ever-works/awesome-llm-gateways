## Overview

OurToken is an aggregator-type OpenAI-compatible gateway aggregating multiple model providers behind a single API key and billing account.

## Features

- Aggregator-type gateway
- OpenAI-compatible
- Aggregates OpenAI, Anthropic Claude, Gemini, DeepSeek, MiniMax, GLM, Kimi and Tencent Hunyuan models
- Single API key and billing account
- Card payment accepted

## Pricing

Paid service with Card payment. Prices change frequently; verify on-site.

## Deployment

Cloud-hosted aggregator service.
