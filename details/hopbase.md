## Overview

HopBase is a hosted API that serves chat, image, video, and speech models from the Claude, GPT, Gemini, and other families through one base URL. It provides OpenAI- and Anthropic-compatible endpoints so existing SDKs work after changing the base URL and API key.

## Features

- Chat, image, video, and speech models
- Claude, GPT, Gemini, and other families
- One base URL
- OpenAI-compatible endpoints
- Anthropic-compatible endpoints
- Existing SDK compatibility
