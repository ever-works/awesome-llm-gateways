## Overview

GPUStack is an open-source LLM inference server and gateway for managing GPU resources and serving multiple models. It provides model serving, resource scheduling, and API access for self-hosted LLM deployments.

## Features

- LLM inference serving
- GPU resource management and scheduling
- Multi-model support
- API gateway for model access
- Self-hosted deployment
- Open-source

## Pricing

Free and open-source. Self-hosted; infrastructure costs borne by the operator.

## Deployment

Self-hosted
