## Overview

Archestra is a platform with an MCP gateway using OAuth and on-behalf-of authentication, an LLM gateway, an A2A gateway, an MCP registry, SSO, RBAC, and guardrails.

## Features

- MCP gateway with OAuth and on-behalf-of authentication
- LLM gateway
- A2A gateway
- MCP registry
- SSO and RBAC
- Guardrails
