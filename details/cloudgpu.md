## Overview

CloudGPU is a hosted OpenAI-compatible API that serves chat, image, speech, and video models through one base URL and API key. It also accepts Messages-format requests, applies per-key rate limits, and bills usage from a prepaid balance.

## Features

- OpenAI-compatible API
- Chat, image, speech, and video models
- One base URL and API key
- Messages-format requests
- Per-key rate limits
- Prepaid balance billing

## Pricing Model

Prepaid balance billing.
