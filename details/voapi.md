## Overview

VoAPI is a China-ecosystem LLM gateway and API management system that provides OpenAI-compatible routing across multiple Chinese and global model providers. It includes user management, cost tracking, and self-hosted deployment.

## Features

- OpenAI-compatible API routing
- Multi-provider support (Chinese and global)
- User management and access control
- Cost tracking and budgeting
- Self-hosted deployment

## Pricing

Free and open-source. Self-hosted; infrastructure and model API costs borne by the operator.

## Deployment

Self-hosted
