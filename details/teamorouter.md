TeamoRouter is a mixed-type AI API relay station serving as an OpenAI / Anthropic / Gemini-compatible gateway for the China/Asia region.

## Features

- OpenAI / Anthropic / Gemini-compatible gateway
- Alipay, WeChat, card and USDT (BEP20 / TRC20 / ERC20) payment support
- Image models on /v1/images/generations with the same key
- Operator-claimed multi-upstream routing
- Claude Code / Codex setup guides
