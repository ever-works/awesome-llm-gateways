## Overview

Teapot Router is a hosted gateway for coding agents that speaks the Anthropic and OpenAI protocols on one key. It provides per-request cost, token, and latency logging, public machine-readable pricing, multi-upstream failover, and credit that never expires.

## Features

- Anthropic and OpenAI protocols on one key
- Per-request cost, token, and latency logging
- Public machine-readable pricing
- Multi-upstream failover
- Credit that never expires

## Pricing Model

Commercial/Per-request billing.
