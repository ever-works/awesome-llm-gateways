## Overview

AISIX is a single static binary from the creators of Apache APISIX that puts one OpenAI-compatible API in front of LLM providers. It routes, secures, caches, and observes LLM and agent traffic.

## Features

- One OpenAI-compatible API in front of LLM providers
- Routes, secures, caches, and observes LLM and agent traffic
- Single static binary
- Created by the Apache APISIX team
