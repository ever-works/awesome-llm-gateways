## Overview

Outrun AI is a hosted API that serves chat, image, video, and speech models from the GPT, Claude, Gemini, and Grok families through one key. It provides OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, and Gemini native endpoints and a USD credit balance endpoint.

## Features

- Chat, image, video, and speech models
- GPT, Claude, Gemini, and Grok families
- One key
- OpenAI Chat Completions
- OpenAI Responses
- Anthropic Messages
- Gemini native endpoints
- USD credit balance endpoint
