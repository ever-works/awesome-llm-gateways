## Overview

Imagera LLM API is a hosted OpenAI-compatible API that serves 320+ language models from 48 labs with one API key. It streams responses as server-sent events and bills per token from the account's Imagera balance.

## Features

- 320+ language models from 48 labs
- One API key
- OpenAI-compatible API
- Server-sent events streaming
- Per-token billing from Imagera balance

## Pricing Model

Per-token billing.
