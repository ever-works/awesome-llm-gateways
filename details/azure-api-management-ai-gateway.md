## Overview

Azure API Management AI Gateway provides Azure API Management policies for LLM APIs, MCP servers, and A2A agent APIs. It includes token rate limits, semantic caching, load balancing, and circuit breakers.

## Features

- Policies for LLM APIs, MCP servers, and A2A agent APIs
- Token rate limits
- Semantic caching
- Load balancing
- Circuit breakers

## Pricing Model
