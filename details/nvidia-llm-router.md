## Overview

NVIDIA LLM Router is part of NVIDIA's enterprise AI software stack, providing intelligent routing for LLM workloads across NVIDIA NIM microservices and external models. It optimizes for performance, cost, and reliability.

## Features

- Intelligent LLM model routing
- Integration with NVIDIA NIM microservices
- Performance optimization
- Cost optimization
- Enterprise-grade reliability
- Multi-model support

## Pricing

Part of NVIDIA AI Enterprise software suite; paid enterprise licensing.

## Deployment
