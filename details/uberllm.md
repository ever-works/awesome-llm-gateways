## Overview

UberLLM is a hosted API that accepts OpenAI and Anthropic wire formats with one key for every model in its catalog. It sends each call to a third-party provider, bills what that provider charged from a prepaid balance, and supports per-key spend limits and per-minute rate limits.

## Features

- OpenAI and Anthropic wire formats
- One key for every model in catalog
- Third-party provider routing
- Per-key spend limits
- Per-minute rate limits
- Prepaid balance billing

## Pricing Model

Prepaid balance billing.
