## Overview

GPT-Load is a China-ecosystem LLM gateway providing OpenAI-compatible API routing, load balancing, and cost tracking across multiple model providers. It is self-hosted and designed for Chinese model ecosystems.

## Features

- OpenAI-compatible API routing
- Multi-provider model support
- Load balancing across endpoints
- Cost tracking and budgeting
- Self-hosted deployment

## Pricing

Free and open-source. Self-hosted; infrastructure and model API costs borne by the operator.

## Deployment

Self-hosted
