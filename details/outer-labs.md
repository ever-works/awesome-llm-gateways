## Overview

Outer Labs is a hosted API for Anthropic Claude and OpenAI GPT models behind one key, over OpenAI Chat Completions, OpenAI Responses, and Anthropic Messages, billed per token from a prepaid balance at published rates.

## Features

- Anthropic Claude and OpenAI GPT models
- One key
- OpenAI Chat Completions
- OpenAI Responses
- Anthropic Messages
- Per-token billing from prepaid balance
- Published rates

## Pricing Model

Per-token billing from prepaid balance at published rates.
