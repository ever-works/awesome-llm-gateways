## Overview

AnyAPI.ai is a hosted API for 400+ models behind one OpenAI-compatible endpoint and an Anthropic Messages endpoint on the same host, with automatic provider failover, per-token billing, and a free tier of 100K tokens per day.

## Features

- 400+ models behind one endpoint
- OpenAI-compatible endpoint
- Anthropic Messages endpoint
- Automatic provider failover
- Per-token billing
- Free tier of 100K tokens per day

## Pricing Model

Per-token billing with a free tier of 100K tokens per day.
