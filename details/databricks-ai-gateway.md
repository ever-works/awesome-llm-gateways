## Overview

Databricks AI Gateway provides managed AI gateway capabilities for routing LLM workloads across Mosaic AI and external model endpoints. It includes governance, cost tracking, and usage controls as part of the Databricks Data Intelligence Platform.

## Features

- Managed AI gateway on Databricks platform
- LLM workload routing
- Model governance and access control
- Cost tracking and attribution
- Usage monitoring
- Integration with Mosaic AI

## Pricing

Usage-based pricing through Databricks platform. Paid enterprise service; no free tier.

## Deployment

Cloud-hosted (Databricks)
