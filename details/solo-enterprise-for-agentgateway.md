## Overview

Solo Enterprise for agentgateway is a commercial agentgateway offering from Solo.io for LLM, MCP, and inference traffic. It provides centralized provider key storage, enterprise IAM integration, and token-based rate limits.

## Features

- LLM, MCP, and inference traffic
- Centralized provider key storage
- Enterprise IAM integration
- Token-based rate limits
