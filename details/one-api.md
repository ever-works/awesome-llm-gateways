## Overview

one-api is an open-source LLM gateway for the China ecosystem that unifies multiple LLM providers behind an OpenAI-compatible API. It includes user management, channel distribution, token tracking, and cost controls for self-hosted deployments.

## Features

- OpenAI-compatible API
- Multi-channel model distribution
- User and team management
- Token usage tracking
- Cost and quota controls
- Self-hosted deployment

## Pricing

Free and open-source. Self-hosted; infrastructure and model API costs borne by the operator.

## Deployment

Self-hosted
