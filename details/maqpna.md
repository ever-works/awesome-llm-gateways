## Overview

MAQPNA is a self-hosted gateway for MCP, A2A, HTTP, and model calls that applies default-deny policy per tool and argument, DLP redaction, human approvals, and budgets. It runs agent sessions in sandboxes and keeps a hash-chained audit ledger.

## Features

- Gateway for MCP, A2A, HTTP, and model calls
- Default-deny policy per tool and argument
- DLP redaction
- Human approvals
- Budgets
- Sandboxed agent sessions
- Hash-chained audit ledger
