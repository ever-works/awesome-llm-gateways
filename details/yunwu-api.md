## Overview

云雾 API (YUNWU) is a mixed-type AI API relay station serving the China/Asia region. It forwards requests to official LLM APIs including OpenAI, Anthropic, and Google Gemini, providing local payment options via Alipay and WeChat.

## Features

- Mixed-type relay station supporting multiple model providers
- Alipay and WeChat payment support
- Marketed on speed and stability
- Full OpenAI API compatibility

## Pricing

Paid service with local payment methods (Alipay/WeChat). Prices change frequently; verify on-site.

## Deployment

Cloud-hosted relay service. Users point their `base_url` at the relay endpoint.
