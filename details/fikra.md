## Overview

Fikra is a hosted OpenAI-compatible API serving open-weight models behind one key, with prepaid per-token billing, M-Pesa and card payment, and context windows up to 1M tokens.

## Features

- OpenAI-compatible API
- Open-weight models
- One key
- Prepaid per-token billing
- M-Pesa and card payment
- Context windows up to 1M tokens

## Pricing Model

Prepaid per-token billing.
