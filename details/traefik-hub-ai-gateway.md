## Overview

Traefik Hub AI Gateway is a control layer on top of the Traefik Hub API Gateway that adds middlewares for chat completion and other LLM traffic, alongside a separate MCP gateway.

## Features

- Middlewares for chat completion and other LLM traffic
- Separate MCP gateway
- Control layer on Traefik Hub API Gateway
