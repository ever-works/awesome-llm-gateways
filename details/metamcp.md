## Overview

MetaMCP is an MCP (Model Context Protocol) gateway for orchestrating AI agent connections to tools and data sources. It provides routing, discovery, and management of MCP servers for AI applications.

## Features

- MCP protocol gateway
- AI agent orchestration
- MCP server discovery and routing
- Tool and data source management
- Open-source

## Pricing

Free and open-source. Self-hosted; infrastructure costs borne by the operator.

## Deployment

Self-hosted
