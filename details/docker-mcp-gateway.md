## Overview

Docker MCP Gateway is a Docker CLI plugin behind the MCP Toolkit in Docker Desktop that runs and deploys MCP servers from the Docker MCP Catalog and serves them to clients through one gateway.

## Features

- Runs and deploys MCP servers from the Docker MCP Catalog
- Serves MCP servers to clients through one gateway
- Docker CLI plugin
- Part of MCP Toolkit in Docker Desktop
