## Overview

Azure AI Gateway provides managed API gateway capabilities for LLM workloads running on Azure, including Azure OpenAI Service. It enables routing, caching, fallbacks, and cost controls across multiple model endpoints.

## Features

- Managed cloud deployment on Azure
- API routing and load balancing
- Caching and response compression
- Rate limiting and quota management
- Authentication and authorization policies
- Cost monitoring and tracking

## Pricing

Consumption-based pricing through Azure API Management and Azure OpenAI Service. Free tier available for API Management; paid tiers scale with usage.

## Deployment

Cloud-hosted (Azure)
