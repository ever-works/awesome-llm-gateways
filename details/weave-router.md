## Overview

Weave Router is a proxy that picks a model for each request from the models you enable. It accepts Anthropic, OpenAI, and Gemini API formats and installs into coding agents such as Claude Code, Codex, and Copilot.

## Features

- Picks a model for each request from enabled models
- Anthropic, OpenAI, and Gemini API formats
- Installs into coding agents (Claude Code, Codex, Copilot)
