## Overview

Gram is an open source stack behind Speakeasy's AI control plane, which manages company-wide access to MCP servers, skills, and assistants with fine-grained permissions, threat detection, and observability.

## Features

- Manages company-wide access to MCP servers, skills, and assistants
- Fine-grained permissions
- Threat detection
- Observability
- AI control plane
