## Overview

Shepherd Model Gateway is an engine-agnostic model-routing gateway that manages worker lifecycles and balances traffic across self-hosted engines such as vLLM, TensorRT-LLM, and SGLang and cloud providers.

## Features

- Engine-agnostic model routing
- Manages worker lifecycles
- Balances traffic across self-hosted engines (vLLM, TensorRT-LLM, SGLang) and cloud providers
