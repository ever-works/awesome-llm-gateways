## Overview

A3M Router is a self-hosted, MIT-licensed TypeScript OpenAI-compatible multi-provider router with parallel ensemble capabilities.

## Features

- MIT-licensed TypeScript OpenAI-compatible multi-provider router
- Parallel ensemble capabilities
- Self-hosted — users supply their own upstream keys
- npm package: adaptive-memory-multi-model-router

## Pricing

Free and open-source under the MIT license.

## Deployment

Self-hosted.
