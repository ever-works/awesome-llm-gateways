## Overview

GoModel is a lightweight gateway with OpenAI-compatible and Anthropic-compatible APIs across providers. It includes response caching, spend tracking, and a dashboard for adding providers.

## Features

- OpenAI-compatible API
- Anthropic-compatible API
- Response caching
- Spend tracking
- Dashboard for adding providers
