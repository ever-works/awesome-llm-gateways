## Overview

Otari is an OpenAI-compatible gateway from Mozilla.ai that routes one endpoint to 40+ providers. It issues virtual keys, enforces budgets, and tracks usage.

## Features

- OpenAI-compatible gateway
- Routes to 40+ providers
- Virtual keys
- Budget enforcement
- Usage tracking
