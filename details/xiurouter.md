## Overview

XiuRouter is an aggregator-type hosted usage-based gateway exposing multiple LLM APIs.

## Features

- Aggregator-type gateway
- Hosted usage-based gateway
- OpenAI Chat Completions and Responses
- Anthropic Messages
- Gemini GenerateContent
- Scoped API keys
- Per-request usage and cost records

## Pricing

Paid service with usage-based pricing. Prices change frequently; verify on-site.

## Deployment

Cloud-hosted gateway service.
