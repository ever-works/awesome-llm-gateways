## Overview

Amazon Bedrock AgentCore Gateway is a managed AWS entry point for agent traffic that turns APIs and Lambda functions into MCP tools, fronts other agents including A2A traffic, and routes inference across model providers.

## Features

- Turns APIs and Lambda functions into MCP tools
- Fronts other agents including A2A traffic
- Routes inference across model providers
- Managed AWS service
