## Overview

Ezkielyna API is a hosted API that serves DeepSeek, GLM, Kimi, MiniMax, Qwen, and other models through one key with OpenAI-compatible and Anthropic Messages endpoints. It logs tokens and cost for each request and bills per token from a prepaid USD balance.

## Features

- DeepSeek, GLM, Kimi, MiniMax, Qwen, and other models
- One key
- OpenAI-compatible endpoint
- Anthropic Messages endpoint
- Token and cost logging per request
- Per-token billing from prepaid USD balance

## Pricing Model

Per-token billing from prepaid USD balance.
