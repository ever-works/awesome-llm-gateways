## Overview

Netlify AI Gateway is a Netlify service that lets code deployed on Netlify call popular AI models without separate provider accounts, credit balances, or API keys.

## Features

- Call popular AI models from Netlify-deployed code
- No separate provider accounts needed
- No credit balances needed
- No API keys needed

## Pricing Model

Commercial/Netlify pricing.
