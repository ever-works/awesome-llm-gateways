## Overview

MCPHub is a self-hosted MCP gateway and control plane that connects local and remote MCP servers once and serves them through stable endpoints with authentication and scoped credentials.

## Features

- Connects local and remote MCP servers once
- Serves through stable endpoints
- Authentication
- Scoped credentials
- Control plane
