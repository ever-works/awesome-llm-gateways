## Overview

llm-d is a distributed LLM inference platform for Kubernetes, providing large-scale model serving with disaggregated inference architecture. It is designed for high-throughput LLM deployments in cloud-native environments.

## Features

- Distributed LLM inference
- Kubernetes-native deployment
- Disaggregated inference architecture
- High-throughput model serving
- Scalable for large models
- Open-source

## Pricing

Free and open-source. Self-hosted; infrastructure costs borne by the operator.

## Deployment

Self-hosted (Kubernetes)
