## Overview

Microsoft Foundry Model Router is a trained language model, deployed like any other Foundry model, that routes each prompt in real time to the most suitable underlying LLM.

## Features

- Trained language model for routing
- Deployed like any other Foundry model
- Real-time prompt routing
- Routes to most suitable underlying LLM
