## Overview

Standard Compute is a hosted router for coding agents that serves OpenAI and Anthropic clients from one key. It picks a model for each request unless one is pinned, and sells monthly plans with a fixed compute budget, returning HTTP 402 once it is used.

## Features

- OpenAI and Anthropic clients
- One key
- Model selection per request unless pinned
- Monthly plans with fixed compute budget
- HTTP 402 when budget is used

## Pricing Model

Monthly plans with fixed compute budget.
