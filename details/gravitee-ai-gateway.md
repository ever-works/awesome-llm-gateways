## Overview

Gravitee AI Gateway is Gravitee's open-source API management platform extended with AI gateway capabilities for LLM traffic orchestration. It supports routing, policy enforcement, observability, and API monetization for AI workloads.

## Features

- Open-source API management
- LLM traffic orchestration
- Policy enforcement and governance
- Observability and analytics
- API monetization
- Self-hosted and cloud deployment

## Pricing

Open-source core available free under Apache 2.0 license; paid enterprise and cloud tiers with additional features.

## Deployment

Self-hosted and cloud-hosted
