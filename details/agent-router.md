## Overview

Agent Router is a gateway built on Envoy Gateway that provides applications with one OpenAI-compatible API for hosted models, self-hosted inference, and MCP servers. It was formerly known as Envoy AI Gateway and is now an Agentic AI Foundation project.

## Features

- OpenAI-compatible API for hosted models, self-hosted inference, and MCP servers
- Built on Envoy Gateway
- Routing, failover, keys, budgets, and logging for model traffic
- One API in front of many providers
