## Overview

Traceloop Hub is an LLM gateway that exposes an OpenAI-compatible API over OpenAI, Anthropic, Azure OpenAI, Vertex AI, and Bedrock. It records every call as OpenTelemetry traces.

## Features

- OpenAI-compatible API
- Supports OpenAI, Anthropic, Azure OpenAI, Vertex AI, and Bedrock
- Records every call as OpenTelemetry traces
- Observability-first design
